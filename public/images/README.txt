PUT YOUR IMAGES HERE
====================
Hero banners (1254 x 418 px, .jpg) go directly in this folder:
  images/banner-men.jpg
  images/banner-women.jpg
  images/banner-collection.jpg

Extra product photos go in images/products/ and are named by product id:
  images/products/<id>-2.jpg
  images/products/<id>-3.jpg
  images/products/<id>-4.jpg
(example: images/products/1-2.jpg)

If a file is missing, the site automatically shows a built-in illustration instead, so nothing breaks.
